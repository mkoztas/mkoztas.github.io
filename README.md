📌 Why This Site in Addition to oztas.rs?
While oztas.rs (Resilience Shift) is dedicated to my strategic projects, circular ecology frameworks, and systemic resilience methodologies, mkoztas.github.io acts as my personal academic and technical archive:
Complete Academic & Professional Integration: Rather than siloing my engineering work, sustainability expertise, real estate credentials, and postgraduate research, this site unifies them as interconnected facets of my professional journey.
Open Science & Reproducibility: It provides executable Python/MATLAB code, Jupyter Notebooks (Google Colab integrated), and open hydro-meteorological datasets directly accessible for peer review and research collaboration.
Living Documentation & Code Hub: Powered by MkDocs and GitHub Actions, it hosts full documentation for my trend analysis tools (TFPW, Sen's Slope, SQMK, SPEI), thesis progress, and software projects.
